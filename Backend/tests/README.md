# Document-generation API tests

This suite covers all **23 document-generating endpoints** inventoried in
[`DOC_GENERATION_APIS.md`](../../DOC_GENERATION_APIS.md), plus report-link lookup,
static downloads and the explicitly unfinished conclusion stub. It extends the
existing tests rather than replacing them. Production controllers are unchanged.

Validation on 2026-10-21: **931 tests passed, 0 failed, 0 skipped**, across 82
suites, using the complete document test runner. These are total suite counts,
including the pre-existing tests.

## Run

From `Backend`, with the project's Node 22 runtime and dependencies installed:

```powershell
npm run test:documents
```

`npm test` runs the same suite, including the existing query-signer helper tests.
The runner discovers `*.test.js` recursively, fixes the timezone to
`Asia/Tashkent`, uses synthetic configuration and starts isolated test processes.
Support modules and fixture regeneration scripts are not executed as tests.

To select tests while retaining the runner's isolated environment:

```powershell
npm run test:documents -- --test-name-pattern="generateSP|createSP"
```

## Exact Word formatting checks

Tests unpack the generated DOCX ZIP and inspect its OOXML rather than only
checking the `.docx` extension or ZIP signature. For the fixed fixtures they
assert:

- Every section's page dimensions/orientation and all seven margins: top,
  right, bottom, left, header, footer and gutter.
- Paragraph alignment, before/after/line spacing, indentation, tab positions,
  breaks, keep properties, borders and text order.
- Text runs, Unicode/XML escaping, font names and sizes, complex-script sizes,
  bold/italic/underline, colors, spaces and field instructions where emitted.
- Tables and nested tables: widths, grid, layout, indentation, borders, row
  heights, split/repeat flags, merged cells, shading and vertical alignment.
- Table default cell margins and each cell's margin overrides. These are
  Word's equivalent of padding, including explicit zero and absent values.
- Style defaults, section headers/footers, package entries and settings.

DOCX distances use twips (1/20 point), font sizes use half-points and border
sizes use eighths of a point. Absence means inheritance/default behavior;
it must not be interpreted as zero padding or a specific installed font.

Fourteen representative raport layouts additionally have full readable JSON
and raw `word/document.xml` baselines in `raport/layouts/`. Raw XML comparison
detects attributes not yet modeled by the inspector. The inspector itself has
tests for zero/false values, nested padding, style inheritance, multiple
sections, header/footer relationships, fields and whitespace.

Statistics fixtures use explicit expected formatting and values for their
sections, paragraphs, tables and cells. XLSX fixtures assert print margins,
orientation, row heights, column widths, merges, fonts, alignment, wrapping,
borders, fills, number formats, frozen panes and chart images where applicable.
Word padding does not apply to ZIP/CSV/SQL outputs.

## HTTP delivery and related routes

[`routes/generatedDocuments.test.js`](routes/generatedDocuments.test.js)
composes real JWT middleware, the raport router, real controllers and real
serializers for all fourteen raport layout fixtures. It follows each returned
URL through the real static download middleware, compares the exact bytes,
checks MIME/length/cache/Unicode download filename, and checks the downloaded
Word layout against its baseline. The upload directory is redirected to a
private temporary fixture directory. This is isolated HTTP integration, not a
live-database deployment test.

`GET /raport/download` covers validation, newest matching report lookup, missing
report, database failure and authenticated stored-link delivery.
[`routes/download.test.js`](routes/download.test.js) covers DOCX/XLSX bytes,
Unicode renaming, extension retention, unsafe filename characters, HEAD, range
requests, missing files and traversal boundaries.

`POST /conclusion/genreate_conclusion` is tested as the current pending stub:
authenticated 200 JSON, no document and no database mutation. It is **not** a
completed generator and is not counted among the 23.

## Isolation and limitations

Prisma is replaced before controllers load. Generated uploads are captured in
memory or copied from synthetic buffers into private temporary directories.
Backup tests replace pg_dump and use synthetic data; real CSV serialization,
encrypted ZIP creation and extraction still run. No real database dump,
registration update or application upload is required.

The fake database records query arguments and mutations; it does not execute
SQL, enforce foreign keys or model transaction/concurrency semantics. Tests
inject representative database failures explicitly.

These tests verify emitted document structure and regression behavior. They do
not prove visual pagination, line wrapping, printer output or font substitution
in Microsoft Word/LibreOffice. No approved visual reference was supplied, and
these baselines characterize the existing output. This is not a claim of 100%
branch coverage or of every possible Word feature being supported.

## Existing defects are visible, not silently fixed

Passing characterization tests can deliberately record an undesirable current
result. See each router README and tests marked as known defects. Examples:

- Missing inputs sometimes return 500; empty relative-list templates can
  return a successful empty document. Weekly denied access returns 500.
- Conclusion updates run in asynchronous `forEach`; draining test work does
  not prove updates finish before the HTTP response in production.
- Some generation failures leave report/link records because metadata is
  inserted before the file is written. Relative queries can connect the wrong
  model as a registration.
- AVR accepts `additional_information` but omits it from the rendered content.
- Some tables serialize oversized percentage widths, omit explicit fonts or
  padding, or omit repeating headers. Chart data/styling columns are offset.
- Global search export fails for Cyrillic attachment filenames. Some backup
  error paths leave temporary files or attempt a late transfer.
- `/api/v1/download` is currently public; tests document this behavior.

Fixing those contracts/layouts requires separate production changes and updated
expectations. Do not regenerate snapshots merely to make a regression pass.
